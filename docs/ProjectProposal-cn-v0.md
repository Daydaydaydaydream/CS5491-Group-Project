# 神经谱容量的残差上下文启发式研究

**团队：** 冯璟哲（72655564）、行晋（72655700）、张正（72655392）

**联系邮箱：** 72655564@cityu-dg.edu.cn

## 研究问题与范围

原始神经谱容量（NSC）将各矩阵容量相加。因此，只交换前馈网络（FFN）的宽度顺序，评分不会改变。我们依据 Zhu、Zhao、Lu 的 NSC 方法和课程归档数据，研究一个问题：用前面 FFN 的残差负载调整后面 FFN 的权重，能否改善架构排序和预算内选择？项目限定于主题说明 Section 3 的核心任务，不开展 Section 4 扩展。我们分别检验评分能否区分顺序，以及这种区分能否改善性能预测。

## 方法与检验

沿用课程 starter 的注意力容量 $A_l$、FFN 容量 $F_l$ 和初始化标准差 $s=0.02$。$d_l$ 是隐藏宽度，$f_l$ 是 FFN 宽度。定义第 $l$ 层的残差负载 $q_l$ 和总评分：

$$
q_l=\tfrac12 d_l f_l s^4,\qquad
S(\alpha)=\sum_l\left[A_l+\frac{F_l}{1+\alpha\sum_{j<l}q_j}\right].
$$

前面各层的负载越大，后面 FFN 的权重越低；$\alpha$ 控制调整强度。$\alpha=0$ 时取消调整，恢复原始 NSC，这就是加性消融。

$s^4$ 来自两次线性映射，并非笔误。假设输入各向同性、与权重独立，每维二阶矩为 $v$；两矩阵的元素独立服从 $N(0,s^2)$。第一次映射后，$\mathbb E[z_i^2]=d_ls^2v$；ReLU 将二阶矩减半；第二次映射后，$\mathbb E[y_i^2]=f_ls^2(d_ls^2v/2)=q_lv$。因此，$q_l$ 表示输出与输入的二阶矩比。它忽略归一化、注意力历史和训练后的缩放。用累积负载降低权重仍是假设，需要实验检验。单矩阵 NSC 的首阶展开 $\ln\det(I+W^TW)\approx\operatorname{tr}(W^TW)$ 的期望为 $dfs^2$；它与两次映射的负载含义不同，不能直接替换。

在两层例子 $d=128,H=4,f=[256,512]$ 中，交换 FFN 宽度后，$\alpha=1$ 的分差约为 $0.005022$，保留 12 位有效数字后仍可区分。$0<\alpha<17.4622$ 时评分偏好窄 FFN 在前；超过该临界值后偏好反转。我们会报告这种方向偏好。开发集候选为 $\alpha\in\{0,0.1,1,10,100,1000\}$，并检查换序、并列和极限情况。评分不同不等于预测更准。

## 数据与评估

使用课程归档的 GPT-2/Transformer-XL 架构集合，来源为 Javaheripi 等的 LiteTransformerSearch。200 条配置均为 `pre_lnorm=False`、`adaptive=True`、`mem_len=192`、`attn_type=0`。开发集和最终集各有 100 条。只用开发集的验证困惑度（PPL，越低越好）选择设置；固定方法、参数和代码后，再用最终集的测试 PPL 评估。

对照包括原始 NSC、位置加权教学示例、加性消融、总参数量、参考 FLOPs、调和平均／最小值聚合和均匀随机选择。排序指标为评分与负 PPL 的 Spearman $\rho$、Kendall $\tau_b$，同时报告并列情况。另比较隐藏宽度相同、总参数量较小值／较大值≥0.90 的架构对，并报告配对数（开发集基线为 180 对）。这些配对可能共享架构，不能视为独立样本。

在 10M、20M、30M、50M 参数预算下，各选择 $k=1,3$ 个架构。报告预算内架构数、所选架构中的最低 PPL，以及它与预算内最低 PPL 的差（遗憾值）。每种方法使用相同预算和 $k$。运行 200 次固定种子的试验，报告均值和总体标准差；波动来自随机选择或并列时的随机决策，不代表训练种子波动。

预算使用归档的总参数量 `total`；NSC 不计嵌入层。参考 FLOPs 按固定键长 384 估算密集运算。10M 档有 49 个架构（开发集 24、最终集 25）。自适应嵌入层（AdaEmb）最大约 837.73 万参数，占总量的比例为 34.4%–93.9%。我们会逐预算分析嵌入层占用是否限制其他组件和方法的区分能力。

## 计算计划与交付

使用普通笔记本 CPU 和 Python 3.9+，不新增模型训练，不需要 GPU 或 LLM API。先复现基线，再实现评分与消融，完成开发集评估并固定方案，最后评估最终集。交付可复现代码、精确命令和报告。每个架构仅有一个归档结果，无法估计训练种子波动。结论只适用于该架构集合；没有性能提升也是有效结果。
