## 研究问题与方法

原始 Neural Spectral Capacity（NSC）将各层容量相加，因此对层配置相同、FFN 宽度分配顺序不同的架构给出相同评分。本项目研究：利用前序 FFN 分支的残差负载调整后续层容量，能否更好地区分计算图，并改善训练后架构的排序或固定参数预算下的选择？

在课程基线的注意力容量 \(A_l\) 和 FFN 容量 \(F_l\) 上，定义残差负载代理 \(q_l=d_l f_l s^4/2\)，并计算

\[
S(\alpha)=\sum_l\left(A_l+\frac{F_l}{1+\alpha\sum_{j<l}q_j}\right).
\]

其中 \(\alpha=0\) 为加性消融，对应原始 NSC 求和。负载代理基于独立高斯线性映射、ReLU 和各向同性输入等假设，是本项目待检验的启发式。我们将先用 FFN 宽度换序示例检查评分是否对顺序敏感，再单独评估其预测与选择效果；敏感性本身不代表性能提升。

## 数据、对照与评估

使用课程 starter 中的 200 个归档 decoder-Transformer 架构及固定划分（100 个开发架构、100 个最终架构；starter 位于 `course/nsc-starter/`）。对照包括原始 NSC、课程位置加权示例、加性消融、参数量、参考 FLOPs，以及 harmonic/min 聚合。报告 Spearman ρ、Kendall τb 和并列情况，并分析同隐藏宽度、参数量差异不超过 10% 的配对；在 10M、20M、30M、50M 参数预算下，对 `k=1/3` 报告最佳所选困惑度和相对遗憾，并与均匀随机选择比较。仅用开发集选择 \(\alpha\) 和方法设置，冻结后再评估最终集。每个架构只有一个归档结果，因此不估计训练种子不确定性。

## 计算计划与预期贡献

使用 Python 3.9 或更高版本及 NumPy、SciPy；核心实验预计可在普通笔记本完成，不需要 GPU 或 LLM API。项目将交付可复现的残差上下文评分、消融和对照分析，并报告该方法在哪些情况下有效或无效，不预设其优于原始 NSC。
