# CS5491 项目规划：NSC 层序上下文评分

## 项目目标

研究在 Neural Spectral Capacity（NSC）中加入 Transformer FFN 层序上下文，能否改善架构排序和固定参数预算下的架构选择。

**研究问题：** 原始 NSC 将逐层容量相加，因而对相同层配置的排列不敏感。我们将测试以前序 FFN 残差负载调整后续层贡献的评分，是否能提供有用的层序信息，并提升课程基准上的评估表现。

**预期方法：** 以课程 NSC 实现为基线，加入层序残差上下文加权；对比原始 NSC、`alpha=0` 加性消融、位置加权示例、参数量/FLOPs、harmonic/min 聚合与均匀随机选择。控制变量的 FFN 宽度换序实验用于检查评分对顺序的敏感性。评分对顺序敏感不等价于预测性能提升。

**正式评估数据：** 课程 starter 及其 200 个 decoder-Transformer 架构规格已归档在 `course/nsc-starter/`，固定划分为 100 个开发架构和 100 个最终架构。先按 starter README 自检并复现开发集基线；开发集用于选择 `alpha` 和方法设置，冻结后才评估最终集。

**指标：** Spearman ρ、Kendall τb、并列数；参数预算 10M/20M/30M/50M、每次选择 `k=1/3` 时的最佳困惑度与相对遗憾；均匀随机选择波动。由于归档每个架构只有一个训练结果，不从该面板估计训练种子不确定性。

**LLM/GPU：** 建议按当前实现计划不使用 LLM；课程说明指出 NSC 主题的核心无需 LLM API 或 GPU，可在普通笔记本运行。

## 2026-10-13 立项书修订后的实验约定

以下是待实施、待开发集冻结的实验计划，不是已完成的实验结果。立项书正文现为 `ProjectProposal-en.md`（英文版，含评估表格）。

- **归一化与解释边界：** `q_l = 0.5*d_l*f_l*s^4` 来自无偏置、独立高斯权重和各向同性输入下两层 ReLU 分支的期望二阶矩比，并非归档 Post-LN 网络的实际跨层方差递推。将前序和 `Q_l` 作为结构上下文特征；不宣称忽略 LayerNorm 是无损近似。LayerNorm 还有可学习仿射参数及 epsilon，不能笼统地说真实输出始终严格零均值、单位方差。相关架构讨论参见 Xiong 等 [On Layer Normalization in the Transformer Architecture](https://proceedings.mlr.press/v119/xiong20b.html)。
- **FFN 研究范围：** 只调整 FFN 是隔离 FFN 宽度分配机制的实验选择，不代表注意力不受上下文影响，也不以“知识存储”推断方差敏感性。增加 `sum_l (A_l+F_l)/(1+alpha*Q_l)` 对照，用同一 FFN 上下文特征检验加权对象的影响；它仍不是完整注意力负载模型。
- **阻尼敏感性：** 主形式 `w(x)=1/(1+x)`，对照 `exp(-x)`，其中 `x=alpha*Q_l>=0`。两者在零点取 1，导数为 -1，但尾部不同。这是可解释的形式对照，不是信息论推导。保留原始 NSC、位置示例、加性消融、参数量、参考 FLOPs 和均匀随机选择；harmonic/min 不再作为必做项，控制项目范围。
- **排序反转的数学解释：** 固定架构时 `dS/dalpha = -sum_l F_l*Q_l/(1+alpha*Q_l)^2 <= 0`。两种架构各自单调，并不意味着相对名次不能交叉。两层换序时，令 `a` 为窄 FFN、`b` 为宽 FFN，则 `S_ab-S_ba = alpha*[F_a*q_b/(1+alpha*q_b)-F_b*q_a/(1+alpha*q_a)]`。小 alpha 下差异由 `F_a*q_b-F_b*q_a` 决定；alpha 趋于无穷时差异趋于 `F_a-F_b`。这解释可能的方向反转，并不证明预测有效。报告全部候选 alpha 的开发集表现及换序方向，不隐去不利区间。
- **方法选择：** 主形式的 alpha 候选为 `{0,0.1,1,10,100,1000}`，以开发集 Spearman rho 最大为选择准则；相同则选较小 alpha。指数形式及共同加权仅作预先声明的对照，各用相同候选和选择规则。冻结规则与代码后才访问最终标签；最终集不用于重新选择权重形式。
- **配对依赖：** 区间以架构而非边／配对为重采样单位。在每个划分内按隐藏宽度分层、有放回抽取架构，保留所有方法的同一次抽样；重新构造满足参数比条件的不同原始架构配对。原始架构 i、j 的配对按其抽样频数乘积加权，同 ID 自配对排除。固定种子，2,000 次 bootstrap，报告指标及相对 NSC 差值的百分位 95% 区间；报告退化重采样比例，指标无定义时不填零。它描述架构面板的抽样敏感性，不是训练种子显著性，也不将 180 对视为 180 个独立观测。
- **嵌入混杂：** 原稿中的 AdaEmb 最大 8,377,280 参数、占比 34.4%–93.9% 仅适用于总参数≤10M 的 49 个配置。全体 200 个配置的对应范围是最大 25,915,392 参数、占比约 7.8%–97.9%。大占比本身不能证明 PPL 被嵌入层主导。预先以 `adaptive,n_token,d_embed,d_model,div_val,cutoffs,tie_weight,tie_projs` 的相同配置分组，逐预算报告样本数、嵌入占比及组内比较；所有分组均披露，不挑选有利组。组内架构少于 10 个时仅报告描述统计；候选少于 k 时标记不可评估，不补样、不替换主预算。分组是混杂诊断，不是因果识别；不改变四档主预算或据最终标签重新划组。
- **交付基调：** 以量化启发式适用边界为研究目标。保留课程要求的证据边界，不承诺无法由现有归档数据支持的信息论归因或训练性能提升。
