# 数据

课程核心实验预期使用 starter 提供的 200 个 decoder-Transformer 架构配置，并遵循其固定的开发集/最终集划分。目前课程 starter 压缩包和评测数据尚未放入本地仓库。

上游 NSC 仓库还列出 GPT-2/LiteTransformerSearch、FlexiBERT、AutoFormer、NATS-Bench、MobileNetV3、Transformer-XL 与 LoNAS 等外部资源。它们不自动构成本课程固定面板；任何替代数据只能用于开发调试，不能替代正式开发/最终评估。

接入数据时保留原始来源及许可说明。开发过程不得查看最终集结果。归档面板每个架构仅有一个训练结果，不支持训练随机种子不确定性估计。
